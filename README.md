# MyLocations
My locations - Developing an app that uses Core Location to capture the user’s current GPS coordinates. Implementing MapKit to display saved locations and visualize user-selected favorites. Integrating the camera and photo library to allow users to attach photos to specific locations. Building a Core Data–backed storage system to persist location details, notes, and images.

User manual:

App initiates - User taps Get location button in order to fetch his current location - then Tag location in order to save the location. In the Tag Location Tab he enters the details of the Location. He has access to a full list of his locations and he can also check them on a live map
